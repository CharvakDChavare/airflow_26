# Apache Airflow Learning & Practice

This repository contains my hands-on practice and learning journey with **Apache Airflow** as part of my Data Engineering learning.

I am using this repository to experiment with different Airflow concepts, build DAGs, understand workflow orchestration, and practice implementing data pipelines.

## 🚀 What I'm Learning

Through these exercises, I am practicing:

- Creating Apache Airflow DAGs
- Tasks and task dependencies
- DAG scheduling
- Cron expressions
- Catchup and backfilling
- TaskFlow API
- Python tasks
- XCom
- Task dependencies
- Parallel task execution
- Triggering DAGs
- Parent and child DAGs
- Workflow orchestration
- Incremental data loading
- Data pipeline concepts
- Airflow operators
- Timezones and scheduling
- Debugging Airflow DAGs
